
# OWASP Top 10 Android App Bug

- M1: Improper Credential Usage – Mishandling of user credentials, including hardcoded credentials or insecure transmission/storage. 
- M2: Inadequate Supply Chain Security – Vulnerabilities introduced through third-party libraries, compromised build environments, or trojanized releases. 
- M3: Insecure Authentication/Authorization – Weak authentication mechanisms, IDOR vulnerabilities, or missing server-side authorization checks. 
- M4: Insufficient Input/Output Validation – Lack of validation allowing injection attacks (e.g., XSS, SQLi) or remote code execution. 
- M5: Insecure Communication – Use of outdated TLS versions, lack of certificate validation, or transmitting sensitive data over unencrypted channels.
- M6: Inadequate Privacy Controls – Insufficient sanitization of logs, excessive data collection, or improper handling of user privacy settings.
- M7: Insufficient Binary Protections – Lack of obfuscation or anti-tampering measures, allowing reverse engineering or code modification.
- M8: Security Misconfiguration – Shipping debug builds, using default passwords, excessive permissions, or exporting internal activities.
- M9: Insecure Data Storage – Storing sensitive data (PII, tokens) in plaintext, unencrypted databases, or world-readable files. 
- M10: Insufficient Cryptography – Use of weak algorithms, hardcoded keys, or flawed cryptographic implementations.
